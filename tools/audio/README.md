# Sound sources

- `floppy_spin`, `floppy_step`, `floppy_seek` (computer floppy drives): cut by `floppy-cut.py` from
  "Floppy drive sounds.ogg" by AlepouTheFox, Wikimedia Commons, CC0
  (https://commons.wikimedia.org/wiki/File:Floppy_drive_sounds.ogg). The seek is that recording's step repeated
  every ~6 ms.
- `floppy_insert`, `floppy_eject`: BigSoundBank "Floppy disk (3.5"), input" (ID 1395) and "output" (ID 1397), CC0
  (https://bigsoundbank.com/floppy-disk-3-5-input-s1395.html, .../floppy-disk-3-5-output-s1397.html); trimmed to
  0.8 s, 40 Hz high-pass, faded, -2 dB.
